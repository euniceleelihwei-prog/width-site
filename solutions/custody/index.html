Custody challenges

What Custodians and WaaS Providers Face

01

Every Client Needs Compliance, and Each Buys It Alone

A separate KYT contract per client is slow and expensive, so smaller clients often skip it.

How DART solves it

  • Integrate once and screen deposits and withdrawals for every enterprise wallet on your platform
  • Downstream clients get KYA and KYT out of the box, with nothing to procure

ProofA wallet and custody infrastructure provider runs 17,000–18,000 screenings every working day.

02

Different Clients, Different Risk Appetite

Payment firms, trading platforms and token projects tolerate very different levels of risk. One ruleset won't fit.

How DART solves it

  • One ruleset per client: copy a built-in ruleset and set thresholds and rules to each client's policy
  • Pass the client's ruleset with each screening; results and snapshots are kept per client

ProofBuilt-in rulesets are read-only and custom ones are saved separately, so you can show which rules applied at any point.

03

Bad Funds Get Swept Into the Main Wallet

Once deposit addresses sweep into an MPC main wallet, tainted funds mix with clean ones and are hard to separate.

How DART solves it

  • Screen before sweeping: run inbound screening on deposits and pause the sweep for any address that hits
  • Trace upstream in time order, counting only money that arrived before it left

ProofThere's a ready-made guide for adding KYT to MPC sweeps, and we map the flow with you during onboarding.

FAQ

Questions Custodians Ask

Can each downstream client have its own rules?

Yes. Copy a built-in ruleset per client and pass it with each screening. Results and snapshots are kept per client.

Where in the sweep flow should screening happen?

Screen the source when a deposit lands and before it sweeps. Pause the sweep for any address that hits and hand it to the client, so tainted funds never mix into the main wallet. We map the flow with you during onboarding.

What about existing addresses?

Import them by CSV for a one-off rescreen, then switch to real-time screening.

Will volume affect speed?

Sanctions checks return in under a second and sync calls return directly. For large batches and deep traces, async mode returns a job ID to poll, so deposits and withdrawals aren't blocked.

Can we use the console and the API together?

Yes. Console, REST API, MCP and CSV batch share one account, one quota and the same snapshots.

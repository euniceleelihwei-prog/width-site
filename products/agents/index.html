FAQ

MCP Questions

Which AI tools work with DART?

Any MCP client, including Claude Code, Cursor and Codex. Add the configuration above with your API key and the tools appear.

How is MCP different from the API?

Same capabilities. Every MCP tool maps to an HTTP endpoint of the same name. MCP suits agents calling tools directly; the API suits system integrations. Both share one account, one quota and one set of snapshots.

Could an agent change rules by mistake?

Built-in rulesets are read-only, so an agent can only edit the copies you created. Every snapshot records which ruleset version ran.

How should an agent explain results to end users?

Results list the rules, paths, hops, amounts, shares and points behind every score, so an agent can explain them in plain language. When showing results to the public, say which kind of public source was hit rather than labelling a person's address.

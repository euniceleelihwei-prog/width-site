常见问题

关于 MCP 接入

支持哪些 AI 工具？

支持 MCP 协议的都可以，例如 Claude Code、Cursor、Codex 等。把上面的配置加进去，填上 API Key 就能用。

MCP 和 API 有什么区别？

能力一样，每个 MCP 工具对应一个同名的 HTTP 接口。MCP 适合 AI 助手直接调用，API 适合系统集成。两者共用一个账号、同一份额度和同一批快照。

AI 会不会误改规则？

内置规则集只读，AI 只能修改你自己复制出来的规则集。每次筛查用的是哪一版规则，快照里都有记录。

筛查结果怎么让 AI 解释给用户？

结果里列明了命中的规则、路径、跳数、金额、占比和加分，AI 可以据此用自然语言解释。建议对外展示时只说命中了哪类公开来源，不给个人地址下定性。
